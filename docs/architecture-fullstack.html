Harness 是核心难点

  • • 指标四类：检索 / 生成 / 系统 / Agent
  • • 预算制门槛：更准但更贵更慢 → 不通过
  • • 轨迹回放：不调模型复现决策路径
  • • 故障注入矩阵验证降级路径
  • • 影子评测 + 标注台形成数据飞轮

面试可讲的重难点

  • • 引用精度 ↔ 拒答率成对权衡
  • • Agent 成本控制与无进展检测
  • • 离线 / 内网部署与索引灰度重建
